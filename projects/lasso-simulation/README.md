# LASSO推定量のバイアス・分散シミュレーション（R）

**区分**：大学「計算機統計学A」中間課題（個人課題）

## 目的と内容

LASSOによる係数推定について、観測誤差や真の回帰係数を変えた場合に推定量のバイアス・分散がどう変わるかを、シミュレーションで調べる。

- 設定：標本サイズ `n=30`、説明変数 `p=10`
- 既知の回帰係数から模擬データを生成し、`glmnet::cv.glmnet` によるLASSO推定を反復
- 基準条件、誤差増大、係数縮小・拡大で比較
- コードでは1条件につき1,000回の反復を設定

**[整理・修正版のRコード](lasso_bias_variance.R)**

## コードの位置づけと再現性

課題をもとに整理した**再実装**で、授業に提出したソースと完全に同一ではない。元コードの一部で変更後の真の係数がデータ生成に反映されない不整合があったため修正した。

`glmnet` が必要。実行コマンドは `Rscript lasso_bias_variance.R`。R環境での動作確認・数値照合は**未実施**であり、数値結果は掲載していない。


**原課題との違い**：授業で作成したColabのRコードでは、係数を小さく／大きくしたケースのデータ生成に変更前の `beta_true` が残っていた。公開版 `lasso_bias_variance.R` はその箇所を修正した再実装であり、元の提出内容と区別している。
