# 映画評価データから利用者の嗜好を分類（R）

**区分**：大学「多変量データ解析B」期末レポート（個人課題）  
**データ**：[MovieLens 100K](https://grouplens.org/datasets/movielens/100k/)

## 目的と規模

映画の評価傾向から、利用者に共通するジャンル嗜好を発見できるか検討。元データは**943人、1,682作品、10万件の評価**。8ジャンルすべてに評価のある**861人**を分析対象にした。

## 分析と担当範囲

1. 利用者ごとにジャンル別の平均評価を集計した。
2. 最初は「好み」よりも、全般的に高く評価する人／低く評価する人の差が強く出た。
3. そこで**ジャンル嗜好得点＝ジャンル別平均評価－その利用者の全作品平均評価**に変更し、評価の付け方の個人差を調整した。
4. 階層型クラスタリング（Ward法など）とk-means法を実施し、距離、クラスター数、初期値を変えて比較した。

## 結果

2群で比較すると、Ward法は526人／335人、k-means法は537人／324人。両手法で同じ側に分類された利用者は**861人中752人（87.3%）**だった。これは分類結果の一致度であり、予測精度ではない。

一方の群はAction・Adventure・Sci-Fi・Warを比較的高く評価し、もう一方の群はDramaを相対的に高く評価する傾向があった。

## 限界・公開状況

2群への単純化では少数の嗜好を捉えにくく、109人は手法間で分類が一致しなかった。評価した映画の本数や作品構成による影響も残る。
