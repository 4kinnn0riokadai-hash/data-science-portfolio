# 映画評価データのクラスタリング：分析結果の詳細

> 2026年11月24日時点で確認した大学「多変量データ解析B」期末レポートから、個人情報を除いて整理した分析記録。**原文PDFの公開ではありません**。結果数値は当時のレポートから転記し、現在の再実行による検証は行っていません。

## 研究課題

MovieLens 100Kの**943人・1,682作品・評価100,000件**を用い、ジャンル評価から視聴者の嗜好傾向を分類できるか調べた。ジャンルはDrama、Comedy、Action、Thriller、Romance、Adventure、Sci-Fi、Warの8種類。8ジャンルすべての評価がある**861人**が分析対象。

## 初回分析からの改善

利用者ごとのジャンル平均を直接クラスタリングすると、「映画の好み」ではなく全体的な採点の高低が大きく反映された。そこで**ジャンル嗜好得点＝利用者のジャンル別平均評価－その利用者の全作品平均評価**を作り、嗜好の差に注目した。

## 手法

- 階層型クラスタリング：ユークリッド距離／Ward法を中心に、最長距離法・マンハッタン距離＋群平均法とも比較
- クラスター数：2・3・4を比較
- k-means：2・3・4群を比較。初期値を1組だけ使う場合と30組使う場合の違いを確認
- 両手法の群平均と分類結果の一致度を比較

## 各手法による人数構成

| クラスター数 | Ward法 | k-means |
|---|---|---|
| 2 | 526 / 335 | 537 / 324 |
| 3 | 526 / 290 / 45 | 474 / 257 / 130 |
| 4 | 380 / 290 / 146 / 45 | 332 / 221 / 209 / 99 |

2群とした際のジャンル嗜好得点：

| ジャンル | Ward群1 | Ward群2 | k-means群1 | k-means群2 |
|---|---:|---:|---:|---:|
| Drama | 0.107 | 0.183 | 0.106 | 0.188 |
| Comedy | -0.135 | -0.147 | -0.166 | -0.096 |
| Action | 0.076 | -0.268 | 0.087 | -0.298 |
| Thriller | -0.034 | -0.049 | -0.006 | -0.049 |
| Romance | 0.121 | 0.001 | 0.102 | 0.027 |
| Adventure | 0.159 | -0.402 | 0.164 | -0.429 |
| Sci-Fi | 0.179 | -0.331 | 0.205 | -0.392 |
| War | 0.314 | 0.019 | 0.335 | -0.025 |

**861人中752人（87.3%）**が両手法で同じ側の群に入った。これは手法間の一致率であり、予測モデルの正解率ではない。

## 考察と限界

- 一方はAction・Adventure・Sci-Fi・Warを比較的好み、もう一方はDramaを相対的に高く評価する傾向があった。
- ただし、残る109人は両手法で分類が異なる。
- 距離関数・結合法を変更すると、分類される人数の構成は大きく変化した。
- 複数ジャンルにまたがる作品や評価作品の選択偏りの影響がある。8ジャンルを評価した利用者だけの分析結果を、一般の映画視聴者全体へ直接一般化できない。
