# 生態学データのベイズ統計解析（R）

**区分**：大学「ベイズ統計基礎」レポート（個人課題）

## 目的

生態学データに含まれるFID（Flight Initiation Distance：逃避開始距離）に関連する要因を調べ、説明変数や事前分布の設定によって推定結果がどう変わるかを検討した。

## 分析と担当範囲

1. FIDと候補説明変数の関連を可視化し、生態学的な意味と合わせて候補を選択。
2. Rを用いてベイズ回帰モデルのパラメータをMCMCで推定。
3. 複数の説明変数の組み合わせについて、信用区間とPSIS-LOO交差検証を確認。
4. 事前分布の設定を変更した複数モデルの係数推定値・予測性能を比較した。

## 主な結果と限界

提出レポートでは `Feeding + DT + PA` を採用。検討した事前分布の間で係数の符号や推定値は大きく変わらず、PSIS-LOOによる比較でも予測性能の明確な差は見られなかった。
