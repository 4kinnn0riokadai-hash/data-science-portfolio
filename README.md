# データ分析・統計解析ポートフォリオ

岡山大学の講義・個人演習で取り組んだ、**Rによる統計解析**と**Pythonによるデータ分析・機械学習**の記録です。分析目的、取り組んだ範囲、工夫した点、結果と限界をできるだけ明確にまとめています。

> **活動の位置づけ**：掲載内容は大学の授業課題・個人演習であり、企業での開発実務や査読付き論文ではありません。講義配布資料や配布データ、個人の学籍番号等は公開していません。成果の再現性については各ページに記載しています。

## 品質チェック

GitHub ActionsでNotebookのJSON形式、Pythonコードの構文、Markdown内のローカルリンクを確認します。これは**静的検査**であり、Rコードや機械学習の数値的な正しさ、Kaggleデータでの実行成功を証明するものではありません。詳細は[公開・検証チェックリスト](PUBLICATION_CHECKLIST.md)を参照してください。

## 使用した言語・技術

- **R**：回帰分析、クラスタリング、ベイズ推定（MCMC）、空間統計、LASSO、モデル比較
- **Python**：pandas、NumPy、scikit-learn、LightGBM、XGBoost、データ前処理
- **重視すること**：分析目的に合った指標・特徴量を定義すること、複数手法を比較すること、結果の限界を説明すること
